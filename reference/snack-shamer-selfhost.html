What's in the file

Same set as the original print: both dials, both springs, and front and back plates for variants A and B. Your text is a separate part on each front plate, so you can give it its own filament.

Two-colour lettering

Lettering occupies the first 0.8 mm. With 0.2 mm layers, add a filament change at 0.8 mm and the letters come out in the first colour. Print the front plates on their own if you do this.

Keep it legible

Long names shrink to fit the plate. Below about 1.8 mm tall, letters get mushy on a 0.4 mm nozzle, so try a nickname or a shorter tagline.
